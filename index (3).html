Lo que cargues acá se guarda automáticamente en el repositorio de GitHub — el link publicado queda actualizado para todos, sin que tengas que subir nada a mano.

1 Conectar una Google Sheet

Modo recomendado: "Libro completo" — trae TODAS las hojas (Tableros asesores, PP, Refi, Comisión, Automático) de una sola vez y reparte cada una donde corresponde.

Libro completo (recomendado)

Usá el link normal de compartir

Abrí tu Google Sheet y copiá la URL de la barra de direcciones tal cual (algo como .../spreadsheets/d/TU_ID/edit...). El archivo tiene que estar compartido como "Cualquiera con el enlace puede ver". No hace falta "Publicar en la web" para este modo.

Una sola hoja (alternativa)

Archivo → Compartir → Publicar en la web

Si preferís conectar una sola pestaña (por ejemplo solo Calidad), publicá esa hoja puntual en formato CSV y pegá ese link, eligiendo "Una sola hoja" abajo.

Conectar y traer datos

2 Subir un Excel directo

Subís el libro completo de tu Control de Gestión (mismo archivo .xlsx de siempre) y se procesa entero de una sola vez: reparte automáticamente cada hoja donde corresponde — Tablero de Asesores y Cajones. El archivo se procesa en tu navegador, no se sube a ningún servidor.

→ Tablero de Asesores

Hoja "Tableros asesores" / "Tiempos y productividad"

Contactos, efectividad, colocación, conversión, cumplimiento, ocioso y refinanciación por asesor — alimenta el ranking, la ficha del asesor y el resto de la pestaña Tablero de Asesores.

→ Cajones

Hojas "Comisión", "Refi", "PP…" y "Automático"

Cartera completa, refinanciaciones, promesas de pago y envíos automáticos del cajón — alimenta la pestaña Cajones (y su resumen cruzado en Tablero de Asesores). El "perf" de Cajones también se recalcula solo a partir de los asesores recién cargados.
